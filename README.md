# Power BI Sales Performance Dashboard

## 📌 Project Overview

This Power BI project presents a comprehensive dashboard that analyzes sales performance across different product brands and regions. It helps stakeholders monitor KPIs like total transactions, profit, profit margins, return rates, and compares actuals against set goals for the current month. The data is visualized to provide insights into business performance and areas for improvement.

## 🧩 Problem Statement

Businesses often struggle to understand performance trends across product lines and regions due to the volume and complexity of sales data. Without a visual and analytical dashboard, decision-makers lack the clarity to act quickly on critical insights such as underperforming brands, high return rates, or missed revenue targets.

The goal of this project was to build a **Power BI dashboard** that enables:

- Quick identification of top-performing brands.
- Analysis of current month performance versus goals.
- Tracking of return rates for quality control.
- Weekly revenue trends for forecasting and planning.

## 📊 Dashboard Features

### ✅ Brand Performance Analysis

| Metric | Description |
|--------|-------------|
| **Total Transactions** | Number of successful transactions per brand. |
| **Total Profit** | Total profit generated by each brand. |
| **Profit Margin** | Profitability of each brand as a percentage. |
| **Return Rate** | Percentage of products returned per brand. |

- Top brands include: **Hermanos**, **Tell Tale**, **Ebony**, and **Tri-State**.
- Brands like **BBB Best** and **Plato** have notably high profit margins (above 62%).

### 📅 Monthly KPIs

| KPI | Current Value | Goal | Performance |
|-----|----------------|------|-------------|
| **Transactions** | 18,325 | 17,339 | +5.69% |
| **Profit** | $71,682 | $67,870 | +5.61% |
| **Returns** | 569 | 482 | +18.05% (higher return rate) |

- **Insight**: While sales and profit targets were exceeded, returns increased significantly, suggesting a potential quality or satisfaction issue.

### 🌎 Regional Insights

- Sales activity is spread across **USA**, **Canada**, and **Mexico**.
- Interactive map visuals highlight state/province-wise distribution.
- Locations include **WA**, **CA**, **OR**, **DF**, **Zacatecas**, **Guerrero**, etc.

### 📈 Revenue Trends

- Weekly revenue tracked over time (e.g., from Jan 1997 to Jul 1998).
- Comparative **Revenue vs. Target** chart aids in evaluating sales strategy effectiveness.

## 🛠 Tools & Technologies

- **Power BI Desktop** – data modeling and dashboard creation
- **DAX** – for creating KPIs and calculated fields
- **Bing Maps & OpenStreetMap** – for geospatial visualization
- **Microsoft Excel/CSV** – assumed data source for product and transaction data

## 📍 Conclusion

This Power BI dashboard serves as a centralized analytical tool for monitoring and improving sales performance. It enables data-driven decisions by providing insights into top brands, return behaviors, and revenue patterns.
